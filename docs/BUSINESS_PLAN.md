# VEXScouting 商业计划（副业级稳定收入）

> 目标：把现有平台做成一个**有真实付费用户、能覆盖成本并产生稳定副业收入**的 SaaS。
> 约束：单人/小团队，低投入，**付费方尚未确定 → 验证优先**。
> 日期：2026-06-01

---

## 0. 一句话定位

> 不是"又一个看 VEX 数据的网站"，而是**"帮你在联盟选择和比赛现场赢下决策"的工具**——
> 在公开 API 统计之上，叠加**预测决策**与**你自己的现场球探数据**。

变现的核心假设（待验证）：
- **H1**：竞赛队愿意为"联盟选择助手 + 现场球探"按赛季付费（$10–25/赛季）。
- **H2**：教练/学校/多队项目愿意为"组织级多队管理"按年付费（$50–200/年）。
- **H3**：赛事方愿意为"品牌排名大屏/直播胜率叠加"按场或按年付费（高客单价、低频）。

本计划的第一目标，是用最小成本判断 **H1/H2/H3 哪个为真**。

---

## 1. 市场

### 1.1 规模（估算，需在调研阶段校准）
- VEX 生态（REC Foundation）：VRC + VIQRC + VEXU 全球**数万支队**（近年披露 2.5 万+ 支量级）。
- 本平台 season 197 已为 **1740 支 VRC 队**算出 perf-score（见 `docs/perf-v2-preview-197-2026-04-27.md`），说明数据管线已能覆盖真实规模子集。
- 粗略漏斗（保守）：
  - 全球活跃 VRC 队（SAM 取作目标）：~1 万支
  - 现实可触达 + 愿意尝试工具：5–10%
  - 最终付费转化：1–3%
  - → **可达成的付费队规模：约 50–300 支**。这正好落在"副业级"区间（见 §6 测算）。

### 1.2 用户与买单人是分离的（关键）
- **用户**多为学生（操作手、scout、队长）——付费意愿低、自己没钱。
- **买单人**通常是：家长、教练/mentor、学校机器人预算、队费池。
- 含义：**定价单位不应是"个人/月"，而应是"按队/赛季"或"按组织/年"**，让队费或学校预算买单。

## 2. 竞品与差异化（必须正视的现实）

| 竞品 | 提供什么 | 价格 | 缺口（你的机会） |
|---|---|---|---|
| **vrc-data-analysis.com** | OPR、质量排名、胜率预测 | **免费** | 只有全球被动统计；无现场球探、无私有数据、无团队协作工作流 |
| **RobotEvents（官方）** | 原始赛事/排名/技能数据 | 免费 | 只是数据源，无分析/决策 |
| 各类社区 app / 表格 | 零散的球探表 | 免费/自制 | 不整合 API 统计，无预测，体验差 |

**残酷的结论**：你**不能靠"更漂亮的统计展示"收费**——那是免费在位者已满足的。

**你能收费的差异化（护城河由弱到强）**：
1. **决策层**：联盟选择助手、对战预测、分层（你已实现 perf-score v2 / tier / alliance 预测）——把它从"埋着的功能"变成"卖点"。
2. **私有数据层（真护城河）**：用户**自己产生的现场球探观察**（机器人能力/可靠性/操作手/机构/掉链子）。竞品抄不走，且只对该队有用 → 高粘性、强续费。
3. **组织层**：多队/学校项目的集中管理与历史沉淀。

## 3. 产品策略：从"看数据"上移到"赢决策"

```
现状：被动统计查看器（免费在位者已占领，难收费）
  ↓
阶段一：决策工具  —— 联盟选择助手（复用 perf-score v2，差异化卖点）
  ↓
阶段二：私有数据  —— 手机端现场球探录入（护城河，提高续费）
  ↓
阶段三：组织放大  —— 学校/多队项目版（提高客单价）
```

### 杀手锏：联盟选择助手（Alliance Selection Assistant）
- 输入：某场即将到来的赛事 / 当前赛事。
- 输出：一份**排好序的"该选谁"挑选清单**，合并 = 你已有的 API 统计 + 预测 +（阶段二后）该队自己的现场观察。
- 时机价值：alliance selection 是 VEX 比赛里**信息差最值钱的 5 分钟**——这是用户愿意为"赢"付费的瞬间。

## 4. 商业模式与定价（建议）

**Freemium，按队/赛季为主，组织/年为辅。**

| 层级 | 价格（建议起点） | 内容 | 目的 |
|---|---|---|---|
| Free | $0 | 搜索 + 基础统计 + 有限对比 | 引流、对标免费在位者 |
| **Team Pro** | **$15 / 赛季 / 队** | 联盟选择助手、高级预测、无限对比、赛前预扫报告、现场球探录入 | 主力收入（H1） |
| **Program** | **$99 / 年 / 组织** | 多队管理、跨队历史、共享球探库、成员席位 | 提高客单价（H2） |
| Event（可选） | 按场报价 | 品牌排名大屏 / 直播胜率叠加 | 高客单价试点（H3） |
| Supporter（兜底） | 自愿 $3–5 | 徽章，不锁功能 | 不破坏免费定位下的额外收入（E） |

收款：**Stripe**（订阅 + 一次性）。赛季制契合 VEX 的赛季节奏，降低"按月"对学生的心理摩擦。

## 5. 验证计划（因为"谁付费"未知 —— 这是当前最重要的部分）

**先卖，再造。** 不要先花 1 个月写现场球探功能，再发现没人买。

### 第 0–2 周：客户访谈（零代码）
- 目标：访谈 **15–20 人**，覆盖学生队长 / 教练 / 多队学校协调人 / 1–2 个赛事方。
- 渠道：VEX Forum、Reddit r/VEXRobotics、Discord 社区、本地赛事。
- 核心问题（验证支付意愿，不是问"喜不喜欢"）：
  - 上次 alliance selection 你们怎么决定选谁？信息从哪来？踩过什么坑？
  - 现在用什么工具？为什么不用/用 vrc-data-analysis？
  - 如果有个工具能给排好序的挑选清单 + 记录你们自己的现场观察，**谁会掏钱、掏多少、从哪个预算出**？
- 产出：判定 **H1/H2/H3** 哪个支付意愿最强 → 决定主攻方向。

### 第 2–4 周：假门测试（Fake Door / Pre-sale）
- 在现有站加一个 **"Team Pro / 联盟选择助手"** 的落地页 + 价格 + "提前预订/加入候补" 按钮（接 Stripe 预售或仅留邮箱）。
- 指标：**点击率、留邮率、预付率**。有人真预付 = H1 成立的最强信号。

### 决策门（第 4 周）
- 若 Team Pro 有预付/强候补 → 走 §3 阶段一+二（队/赛季订阅）。
- 若教练/学校信号更强 → 优先 Program 年费版。
- 若都弱、只有赛事方有钱 → 转 B2B 试点（但盘子小，副业可接受）。
- 若全弱 → 不投入，保持免费 + Supporter 捐赠兜底。

## 6. 收入测算（"副业级"到底要多少用户）

成本侧（估算）：Railway + DB + RobotEvents API + Stripe 费 ≈ **$30–80 / 月**。

| 场景 | 付费规模 | 年收入（粗略） | 含义 |
|---|---|---|---|
| 覆盖成本 | 40 队 × $15/赛季 ×（~2 赛季/年） | ~$1,200 | 服务器/API 不再倒贴 |
| 副业下限 | 100 队 × $15 × 2 | ~$3,000 | 明确的副业零花钱 |
| 副业目标 | 250 队 × $15 × 2 + 20 组织 × $99 | ~$9,500 | 稳定副业级收入 ✅ |
| + 赛事试点 | 上述 + 5 场 × $300 | ~$11,000 | 接近"认真副业" |

**结论**：副业级目标（~$8–10k/年）需要约 **200–300 付费队 + 少量组织**。对应 §1.1 漏斗是**可达成**的——前提是杀手锏功能真的帮人赢，且定价单位踩在"队费/学校预算"上。

| 阶段 | 时间 | 做什么 | 验收 |
|---|---|---|---|

| 持续 | — | Supporter 捐赠、SEO（赛季/赛事页）、社区运营 | 自然流量与口碑 |

## 8. 风险与诚实评估

- **利基 + 免费在位者**：靠它做成大生意很难；做成"有真实付费的副业 SaaS"可行。务必管理预期。
- **学生不付费**：靠"按队/学校预算"定价化解；若访谈发现连队费都不愿出，需重估。
- **季节性强**：收入随赛季波动（赛季内高、淡季低），赛季制定价可平滑。
- **官方风险**：RobotEvents 政策/限流变化会影响数据管线；遵守其 API 条款，做好缓存与降级。
- **维护负担**：现有后端是单文件 monolith（`src/api/server.js`），加支付/多租户前需要适度结构化，避免技术债拖垮副业精力。
