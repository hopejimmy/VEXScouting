# VEX Events API Commercial-Use Clarification

**Status:** Request prepared; written clarification not yet obtained.
**Last checked:** 2026-07-16

## Current Evidence

- The current service is documented as the "Public VEX Events API" at `https://events.vex.com/api/v2`.
- The public API documentation describes endpoints and authentication but does not visibly state a commercial-use license.
- VEX visual identity guidance says commercial use of VEX brand assets requires written permission. This is a separate issue from factual API data, but it means branding must also be handled deliberately.
- Absence of a visible restriction is not written permission. Phase 0 therefore keeps this item open.

Relevant official pages:

- Public API: https://events.vex.com/api/v2
- VEX support: https://support.vex.com/
- VEX branding questions: `branding@vex.com`

## Clarification Request

Send this request to VEX support. Ask support to route it to the owner of the VEX Events API/data license if needed.

```text
Subject: Request for written clarification on commercial use of VEX Events API data

Hello VEX Support,

I operate an independent scouting application called VEXScouting. The
application uses the authenticated Public VEX Events API at
https://events.vex.com/api/v2 to display factual event, team, ranking, skills,
award, and match information.

I am considering charging programs for private collaboration features such as
shared scouting notes, scout assignments, pick lists, exports, and historical
workspace storage. Public VEX event data would remain viewable without payment.
The application would not claim affiliation with or endorsement by VEX.

Could you please confirm in writing:

1. Whether API data from events.vex.com may be used in a commercial or paid
   third-party application.
2. Whether caching, deriving statistical ratings, and displaying predictions
   from that data are permitted.
3. Any required attribution, rate limits, retention limits, or restrictions on
   redistribution.
4. Whether a separate agreement or API plan is required before accepting
   payment.
5. Which VEX names or text references may be used descriptively, and whether
   separate branding permission is required when no VEX logo is used.

I am happy to provide the application URL, screenshots, expected request
volume, caching approach, and privacy policy. Please route this request to the
appropriate API/data licensing contact if necessary.

Thank you,
[Legal name]
[Business or project name]
[Email]
[Application URL]
```

## Contingency

Until clarification is obtained:

- Continue technical validation and free design-partner research.
- Do not represent VEXScouting as affiliated with or endorsed by VEX.
- Do not use VEX logos in paid-product marketing without permission.
- Do not launch broad paid access whose core operation depends on an unresolved commercial data right.
- Keep customer-created scouting data separate so it remains exportable and useful if public-data access changes.
